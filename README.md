# 🌲 Лесное приключение

Текстовый квест на Java. Ты городской житель, который приехал с друзьями на пикник и заблудился в лесу. Твоя задача — найти дорогу обратно к друзьям!

## Возможности

- Текстовый квест с ветвящимися вопросами
- Несколько концовок — 2 победы и 7 поражений
- Хранение имени игрока и счётчика сыгранных игр в сессии
- Возможность начать игру заново после победы или поражения
- Страница приветствия с предысторией

## Технологии

- **Java 11**
- **Maven** — сборка проекта
- **Servlets** — обработка запросов
- **JSP + JSTL** — отображение страниц
- **Tomcat 9** — запуск приложения
- **JUnit 5** — тесты



## Как играть

1. Введи своё имя на странице приветствия
2. Читай текст и выбирай один из вариантов ответа
3. Каждый выбор ведёт к новой ситуации
4. После победы или поражения можно начать заново
